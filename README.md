# Smart Pantry Manager

## Project Description
Smart Pantry Manager is an Android application developed using Java and SQLite. It helps users manage ingredients in their pantry, monitor expiry dates, and discover suggested recipes based on available ingredients.

## Features
- Add ingredients to the pantry.
- View, edit, and delete ingredients.
- Store ingredient names, quantities, units, and expiry dates.
- Validate ingredient details and expiry dates.
- Display expiry warnings and pantry ingredient counts.
- View suggested recipes and preparation instructions.
- Access the application settings screen.
- Store pantry data using SQLite.

## Technologies Used
- Java
- Android Studio
- SQLite
- XML for Android layouts
- Git and GitHub for version control

## Installation and Setup
1. Clone or download this repository from GitHub.
2. If downloaded as a ZIP, extract the project files.
3. Open Android Studio.
4. Select **Open** and choose the Smart Pantry Manager project folder.
5. Allow Gradle to synchronise and download the required dependencies.
6. Select an Android emulator or connect a compatible Android device.
7. Click the **Run** button to build and launch the application.

## Database
The application uses SQLite as its database to store pantry ingredients, including their names, quantities, units, and expiry dates.

### Why SQLite?
SQLite was chosen because it is lightweight, stores data locally on the device, and does not require a separate database server. It is suitable for an Android application that needs to save and retrieve pantry information.
