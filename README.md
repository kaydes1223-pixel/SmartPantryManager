# Smart Pantry Manager

## Project Description
Smart Pantry Manager is an Android application developed using Java and SQLite. It helps users manage ingredients in their pantry and discover recipes based on the ingredients they have available.

## Features
- Add ingredients to the pantry.
- View, edit, and delete ingredients.
- Store ingredient names, quantities, units, and expiry dates.
- Validate ingredient details and expiry dates.
- View suggested recipes based on available ingredients.
- View recipe details and preparation instructions.
- Access the application settings screen.
- Store pantry data using SQLite.

## Technologies Used
- Java
- Android Studio
- SQLite
- XML for Android layouts

## Installation and Setup
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronise.
4. Run the application on an Android emulator or compatible Android device.

## Database
The application uses SQLite to store pantry ingredients, including their names, quantities, units, and expiry dates.
